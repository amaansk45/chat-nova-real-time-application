# ChatNova – Next Generation Real-Time Messaging Application

**Tagline:** Connect. Communicate. Share.  
**Theme:** Premium Dark Navy, Black, and Electric Blue  
**Architecture:** Django 5 + Django REST Framework + Django Channels + React 18 + TypeScript + Tailwind CSS

---

## 🌟 Overview
ChatNova is a modern, scalable, real-time messaging application inspired by WhatsApp, Telegram, and Discord. It features one-to-one private chat, group conversations, audio and video calling via WebRTC, stories/status updates, end-to-end encryption key management, and AI-powered smart assistant features.

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.10+
- Node.js 18+ & npm

### 2. Backend Setup
```bash
cd server
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py runserver 8000
```

### 3. Frontend Setup
```bash
cd client
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to access ChatNova.
